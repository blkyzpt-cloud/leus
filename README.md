# Customized Digital Birthday Card Website

## 🚀 How to Host on Render or GitHub Pages (Free & Non-Expiring Link)

### Option 1: Render (Static Site)
1. Unzip this downloaded archive.
2. Push the files (`index.html` & `README.md`) to a public repository on [GitHub](https://github.com).
3. Log in to [Render](https://render.com).
4. Click **New +** -> **Static Site**.
5. Connect your GitHub repository.
6. Set **Publish directory** to `./` (leave build command blank).
7. Click **Create Static Site**! You will receive a permanent live web link (e.g. `https://my-birthday-card.onrender.com`).

### Option 2: GitHub Pages
1. Push this folder to a GitHub Repository.
2. Go to **Settings** -> **Pages**.
3. Select **Branch: main** and folder **/(root)**, then click **Save**.
4. Your card link is live!
